# Data

Raw measurement files recorded with the Arduino and the Python recording scripts in [`code/`](../code). File names are kept as recorded (`mesures<N>.csv`) so they match the history of the project.

| Folder | File | Rows | Columns | What it is |
|---|---|---|---|---|
| `01_voltage_divider_test/` | `mesures.csv` | 513 | `temps: <ms>, Voltage: <V>` (raw serial text) | First test of the acquisition chain: thermistor read through a simple voltage divider (sketch `thermistor_test`). Voltage between 1.82 V and 2.07 V. |
| `02_calibration/` | `mesures0.csv` | 3 797 | `Ug, Ul, Temperature TMP, Temps` | Calibration run, ~63 min, TMP117 between 3.5 °C and 21.9 °C. |
| `02_calibration/` | `mesures4.csv` | 1 819 | `Ug, Ul, Temperature TMP, Temps` | Calibration run, ~30 min, TMP117 between 8.3 °C and 23.3 °C. |
| `02_calibration/` | `mesures6.csv` | 504 | `Ug, Ul, Uref, Temperature TMP, Temps` | Short calibration run, ~8 min, TMP117 between 4.2 °C and 13.5 °C. The `Uref` column is always 0 because of a bug in the original `etalonnage.ino` (fixed in `code/`). |
| `03_heating_wire/` | `mesures10.csv` | 56 | `Temps, Uref, Ug, Uth, Ufil_chauffant` | Extract from a heating-wire (Joule heating) session used for the heat-capacity measurement. |
| `plots/` | `*.png` | – | – | Figures generated by `enregistrement_chauffe.py` / `record_heating.py` from `mesures10.csv`. |

## Column reference

| Column | Unit | Meaning |
|---|---|---|
| `Ug` | V | Amplified Wheatstone-bridge output (op-amp output, gain ≈ 4.5), read on A0 |
| `Ul` | V | Voltage on the other branch of the bridge, read on A1 |
| `Uref` | V | Bridge reference voltage, read on A2 |
| `Uth` | V | Voltage across the thermistor |
| `Ufil_chauffant` | V | Voltage across the heating wire |
| `Temperature TMP` | °C | Reference temperature from the TMP117 probe (±0.1 °C). A value of `-0.01` means a failed reading |
| `Temps` | s | Time since the Arduino started |

All voltages are 11-bit readings (12-bit ADC reading shifted right by one bit), so one step ≈ 2.37 mV.

> The final calibration dataset (≈ 8 000 s, 3.85 → 30.09 °C) and the outdoor solar campaigns analysed in the report are not stored here. Their results and figures are in the [final report](../docs/reports/MINUTO_Final_Report_EN.pdf).
